# SoftHub

## Честно

Это не мой проект. Это **скопированный сайт**. Я взял дизайн у cheathub.tech, перебил брендинг на SoftHub, вырезал лишнее и залил себе.

Я **не разработчик**. Я не писал этот код с нуля. Я не гений, не сеньор, не «создатель крутого хаба». Я просто умею открыть чужой сайт, посмотреть как он устроен, и повторить у себя. Всё.

Если ты пришёл сюда и подумал «вау, какой крутой сайт, наверное автор топ» — нет. Автор просто крал дизайн.

## Что это

Статический лендинг. Два файла: `index.html` и `contact.html`. Никакого бэкенда. Никакой базы. Никакой «архитектуры». CSS внутри HTML, JS внизу страницы — 40 строк на Turnstile и поиск по карточкам.

## Что тут есть

- **Херо** — «Скачать лучшие читы» с кнопками
- **Три карточки игр** — Minecraft, Minecraft Packs, Roblox
- **FAQ** — шесть вопросов на `<details>`, браузер сам раскрывает, JS не нужен
- **Страница contact.html** — Discord и Telegram
- **Turnstile** от Cloudflare — защита от ботов. Стоит тестовый ключ, свой я так и не вставил

## Откуда что взято

- **Дизайн** — cheathub.tech. Красный минимализм на тёмном фоне. Содрал вручную, посмотрел в инспекторе элементов, повторил
- **Бот-гейт** — Cloudflare Turnstile. Официальный бесплатный сервис, ничего своего
- **Вёрстка, шрифты, иконки** — стандартные, из открытых источников
- **Идея** — не моя

## Чего тут нет

- Своего дизайна
- Своего кода (ну, кроме переделки)
- Уникальных фич
- Продакшн-качества
