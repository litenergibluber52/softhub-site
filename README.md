# SoftHub

Это **не** оригинальный проект. Это **"паста"** — я взял дизайн с другого сайта (cheathub.tech) и переделал под себя: сменил брендинг, вырезал лишнее, добавил бот-гейт, FAQ и страницу связи.

## Что это такое

Простой статический сайт — лендинг с карточками игр и ссылками. Никакого бэкенда, никакой базы данных, никакой «умной архитектуры». Один `index.html`, один `contact.html`, CSS внутри, чуть JavaScript для Turnstile и поиска.

Автор — **не** крутой разработчик. Просто человек, который умеет копировать чужой дизайн и менять его под себя. Всё.

## Что внутри

- `index.html` — главная: херо, три карточки игр, FAQ
- `contact.html` — страница связи (Discord + Telegram)
- Turnstile от Cloudflare — защита от ботов (тестовый ключ, свой ещё не вставлен)
- Деплой через Cloudflare Pages / Vercel

## Откуда взято

- **Дизайн:** cheathub.tech — красный минимализм на тёмном фоне. Скопирован вручную, переделан под SoftHub
- **Бот-гейт:** Cloudflare Turnstile (официальный сервис, бесплатный)
- **Шрифты, иконки, вёрстка:** стандартные, ничего своего

## Лицензия

Какая лицензия, блин. Скачивай, копируй, делай что хочешь. Это же паста.
